# Huduma Birth Queue System

A Django-based system for simulating the birth certificate service flow through:
- eCitizen application simulation
- simulated payment
- Huduma appointment booking simulation
- live queue tracking
- staff queue management
- reports dashboard

## Features
- Applicant registration and login
- Applicant dashboard
- eCitizen simulation
- Huduma appointment simulation
- Automatic queue ticket generation
- Live queue tracker
- Staff dashboard
- Reporting and analytics

## Tech Stack
- Django
- SQLite
- HTML
- CSS
- JavaScript

## Run Locally
1. Clone the repository
2. Create and activate a virtual environment
3. Install requirements
4. Run migrations
5. Start the server

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
